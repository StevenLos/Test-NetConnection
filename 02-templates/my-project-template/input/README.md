# Input

This folder is intentionally empty in the project template.

After copying `02-templates/my-project-template` into `03-projects`, copy one or more CSV files from `02-templates/template CSVs` into this folder, then edit them with real target server names and IP addresses.

Example from the package root:

```powershell
Copy-Item ".\02-templates\template CSVs\minimal-test-plan-template.csv" .\03-projects\my-project\input\test-plan.csv
```
