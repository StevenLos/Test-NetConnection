# Projects

Place real user project files under this folder.

Recommended structure:

```text
03-projects/
  my-project/
    input/
      test-plan.csv
    output/
      results.csv
      summary.csv
```

Start by copying `02-templates/my-project-template` into this folder, then copy a CSV from `02-templates/template CSVs` into your project `input` folder. Then edit the CSV with real target server or device details.

Keep generated result files in the project `output` folder so each project stays self-contained.
